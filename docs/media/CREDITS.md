# LPC demo credits

The screenshot and accelerated demo video show a map assembled by Codex with GPT6 Astra, following a request for the **Liberated Pixel Cup (LPC)** style and a second prompt to refine the house. The map arrangement, tile selection, layers, TSX/TMX files and Wang definitions were created by the AI using existing artwork.

## Artwork

**Lanea Zimmerman (Sharm)** created the LPC base tiles used in this scene: `grass.png`, `dirt.png`, `water.png`, `house.png`, `treetop.png`, `trunk.png`, `rock.png`, `bridges.png`, `barrel.png` and `signs.png`.
